ChordSet is an Expo (SDK 57) / React Native app for musicians: chord sheets, setlists and a tuner. Android first, offline only.

## Before changing Expo/React Native APIs

Expo ships breaking changes every SDK. Check the installed version in `package.json` and the matching docs
(`https://docs.expo.dev/versions/v57.0.0/`) instead of relying on memory. Add native packages with
`npx expo install <pkg>` so versions match the SDK.

## Layout

- `app/` — Expo Router routes only. Each file re-exports a screen from `src/features/*/screens`.
- `src/features/<feature>/` — screens, components, hooks and pure logic per feature.
  - `chords/` transposition + ChordPro parser (pure TS, unit tested)
  - `tuner/` PCM → YIN → frequency → note → cents (pure TS) and `useTuner` (expo-audio)
- `src/database/` — expo-sqlite migrations (`PRAGMA user_version`) and row mappers.
  Screens never write SQL: use `useRepositories()`.
- `src/components/`, `src/theme/`, `src/hooks/`, `src/services/`, `src/types/` — shared code.
- `android/` and `ios/` are generated by `expo prebuild` (Continuous Native Generation). Never edit them;
  use `app.json` or a config plugin in `plugins/`.

## Commands

```bash
npm run validate   # typecheck + lint + prettier + tests (same as CI)
npm start          # dev server (development build)
npm run android    # build and run a development build on a device/emulator
```

Run `npm run validate` before finishing any task.
